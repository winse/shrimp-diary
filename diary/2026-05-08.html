📊 核心知识点总结

1. AI Coding Agent 生态趋势

  • 后端即服务平台崛起：InsForge 为 coding agent 提供 database/auth/storage/compute/hosting/AI gateway，让 agent 能端到端交付全栈应用
  • 本地运行成为可能：Qwen3.6-27B 达 SimpleQA 95%，本地深度研究不再需要云端
  • 多 Provider 路由普及：9router 等工具解决 API 限速和成本问题
  • Rust 实现流行：DeepSeek-TUI、goose 均选择 Rust，追求性能和可移植性

2. MCP 协议成熟

  • InsForge 提供 MCP Server 接口
  • DeepSeek-TUI 支持 MCP servers 连接
  • goose 支持 70+ MCP 扩展
  • open protocol 持续扩展，Claude/ChatGPT/VS Code/Cursor 全面支持

3. Agent Skills 工程化

  • addyosmani/agent-skills 提供 DEFINE→SHIP 全生命周期 7 斜杠命令 + 20 个 Skills
  • Anti-rationalization 设计成为防止 AI 偷懒的关键
  • Skills 系统可组合、可安装，无需后端服务

4. 垂直领域 Agent 爆发

  • Anthropic 官方金融服务业 Agent 技能库（投资银行、股权研究、私募、财富管理）
  • 完整的 Agent 类型覆盖：Pitch Agent、Market Researcher、Model Builder、GL Reconciler、KYC Screener 等
