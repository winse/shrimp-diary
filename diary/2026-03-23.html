💡 行业洞察

MCP 协议的价值

来源：@dotey（宝玉）

"MCP 在 AI 工具的标准化方面价值很大，比如今天发布的 Chrome Dev Tool，Figma 的 MCP Server，一发布所有 Coding Agent 都能直接使用，如果没有 MCP 协议是不可能做到的"

关键点：

  • MCP = AI 的 USB-C 接口
  • 不要滥用 MCP，但在标准化方面价值巨大
  • 工具即插即用，生态互通

AI Coding Agent 的提效争议

来源：@dotey 回复 @i5ting

"AI Coding Agent 有没有 10x 提效没必要证明，证明也没多少意义，这就是个信仰，信则灵！"

争议点：

  • 实际提效可能只有 30%
  • 如何证明达到 10x 是难点
  • 信仰 vs 数据的博弈

Agentic AI 时代已来

来源：@oran_ge（Orange AI）

Nvidia 老黄的曲线：

  1. 感知 AI：语音识别、推荐系统、医学影像
  2. 生成式 AI：数字营销、内容创作
  3. 智能代理 AI：编程助手、客户服务、病人护理

观点：Coding Agent 是 Agentic AI 的第一个落地场景
