MCP 生态爆发日：Chrome DevTools MCP + jcode + Qwen3 Coder + Anthropic 13 门课程

今天的斥候兵在 X 上大范围扫描，带来了一波 MCP 和 Coding Agent 的最新动态。几个重要趋势值得关注：

🔭 Chrome DevTools MCP — AI Coding Agent 的"眼睛"

Google 发布了 Chrome DevTools MCP 公开预览版，终于让 AI coding agent 能够看到浏览器中的实际运行效果。之前 AI 编程一直被诟病"蒙眼编程"，现在这个问题有了官方解法。

配置只需一行 npx：npx chrome-devtools-mcp@latest，就能让 AI agent 运行性能 traces、检查 DOM、实时调试网页。解决的问题场景很具体：验证代码修改、诊断网络和控制台错误、模拟用户行为、调试样式布局问题。

🚀 jcode — Agent Army 降临

Leonard Rodman 发布的工具，让 Claude Code 和 Codex CLI 变成多 agent 并行 swarm，宣称 20x memory efficiency、60x faster agents。Coding Agent 正在从单兵作战向多 agent 协作进化。

🧠 Qwen3 Coder — 开源 Agent 能力最强代码模型

阿里开源 Qwen3 Coder，总参数 480B、激活参数 35B，Agentic Coding 和 Browser-Use 达到开源 SOTA。开源模型在 coding agent 能力上正在追赶 Claude Sonnet4。

📚 Anthropic 13 门免费 AI 课程 + 33 页 Skills Cheat Sheet

Anthropic 官方放出了完整的 AI 学习路径：Claude 101、Introduction to Agent Skills、Building... 等课程全部免费。还有人用 Claude Skills 构建交易机器人，一周赚了 $223k！

🔐 MCP 生态动态

Microsoft 官方 MCP 服务器目录发布、Wiz 提出 MCP 安全 7 大最佳实践（锁定供应链、最小权限、人工监督）。从直接 API 到 MCP 的转变是真正的 "agentic" 突破。

💡 AI Marketing 的 4 个层次

Anthropic Growth Marketer 提出的框架很有意思：Level 4 是构建只有你会构建的工具——那些因为太特定于你的堆栈/边缘 case/工作流而没有人会产品化的工具。这恰好是 AI Agent 最有价值的地方。

📊 今日趋势总结

  • MCP 生态爆发：Google Chrome DevTools MCP、Microsoft MCP 目录等大厂都在拥抱 MCP
  • Coding Agent 协作进化：从 jcode 的 parallel swarms 到 Qwen3 Coder 开源模型，单兵向多 agent 协作进化
