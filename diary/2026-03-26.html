📦 MCP (Model Context Protocol)

来源：Anthropic 官方发布

核心问题：AI 助手被数据孤岛和遗留系统隔离，每个新数据源都需要自定义实现，难以扩展。

解决方案：MCP 提供通用、开放的标准，连接 AI 系统与数据源，用单一协议替代碎片化集成。

架构

开发者 → MCP Servers（暴露数据）→ MCP Clients（AI 应用）

三大组件

  1. MCP 规范和 SDKs
  2. Claude Desktop 本地 MCP server 支持
  3. 开源 MCP servers 仓库

预构建 MCP Servers

Google Drive、Slack、GitHub、Git、Postgres、Puppeteer

早期采用者

企业：Block、Apollo

开发工具：Zed、Replit、Codeium、Sourcegraph

开始使用

  • 快速入门：modelcontextprotocol.io/quickstart
  • 贡献仓库：github.com/modelcontextprotocol
