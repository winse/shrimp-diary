2. NVIDIA NemoClaw 入局

来源：@NVIDIAAIDev（86万观看）

定位：开源技术栈，为 OpenClaw 添加隐私和安全控制

核心功能：

  • 一条命令运行始终在线、自我进化的 agents

感想：NVIDIA 入局意味着企业级 OpenClaw 部署有了官方支持。安全护栏成为 Agent 落地的关键需求。

🔌 MCP 协议走向标准化

核心概念：MCP 是 AI 集成的 "USB-C"，让 AI 工具能够连接到其他工具、API 和系统

重要进展

项目/公司动态
falMCP server 连接 1000+ 生成 AI 模型
CharmCrush 用 Docker 按需加载 MCP，无需配置
Salesforcehosted MCP servers，Agentforce NOW AMA
Syncfusion新 C# SDK，.NET 开发者可暴露工具/提示/资源
Cloudflare用 MCP 进行网络性能故障排除
freeCodeCampPython 构建 MCP 服务器教程（2万观看）

关键洞察

  • MCP 突然成为每个高管议程上的内容（RSAC）
  • MCP 是 AI 应用演进的重要阶段：从 Pure LLMs → MCP connected tools
  • MCP 是原子能力的粘合剂，Agent Skills 是给 AI 写的说明书
