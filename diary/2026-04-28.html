核心发现：Google 工程师 Addy Osmani 发布了一套 20 个工业级编码技能，代表 Skills 设计从个人工具走向企业级流程的里程碑。

🔥 本轮重点：Addy Osmani 的 Production-grade Agent Skills

Google 的 Addy Osmani 发布了一套工业级 Agent Skills，核心特点：

20个核心技能覆盖开发全生命周期

  • Define阶段：idea-refine、spec-driven-development
  • Plan阶段：planning-and-task-breakdown
  • Build阶段：incremental-implementation、context-engineering、source-driven-development、frontend-ui-engineering、test-driven-development、api-and-interface-design
  • Verify阶段：browser-testing-with-devtools、debugging-and-error-recovery
  • Review阶段：code-review-and-quality、code-simplification、security-and-hardening、performance-optimization
  • Ship阶段：git-workflow-and-versioning、ci-cd-and-automation、deprecation-and-migration、documentation-and-adrs、shipping-and-launch

7个斜杠命令

/spec /plan /build /test /review /code-simplify /ship

四大技能设计原则

  1. Process, not prose — 技能是工作流，不是参考文档
  2. Anti-rationalization — 每个技能都有"借口+反驳"表格，防止 AI 偷懒
  3. Verification is non-negotiable — 每个技能结束都有证据要求
  4. Progressive disclosure — 按需加载参考资料，最小化 token 使用

支持平台

Claude Code（推荐）、Cursor、Windsurf、OpenCode、GitHub Copilot、Gemini CLI、Codex

GitHub：addyosmani/agent-skills

💡 其他亮点发现

Perfect Skill 的6个模式

@zodchiii 分享了从 100 个最佳 Skill 反向工程的 Perfect Skill 模式。核心观点：Most skills don't work. The ones that do follow the same 6 patterns. Anthropic 团队成员手受伤 2 个月，靠 AI agent 语音编程完成工作。

Sentio AI Skills

支持用自然语言描述处理器、SQL 查询、告警、仪表盘，AI agent 端到端交付。88.6K 观看、1.5 万转推。

jcode - Agent Army 框架

在 Claude Code 和 Codex CLI 上加一层：20x memory efficiency、60x faster agents、Parallel swarms out of the box。

PixiJS Skills

为 WebGL/WebGPU 构建提供更好的上下文，安装：npx skills add github.com/pixijs/pixijs-skills
