🤖 MCP (Model Context Protocol) 核心概念

MCP 是 AI 领域的 USB-C 端口，提供标准化方式连接 AI 应用与外部系统。

核心能力：工具执行、模板消息、结构化数据源、文件系统边界查询、用户额外信息请求、MCP Apps 交互式 UI。

三种传输方式：

类型环境用户数输入方式
stdio本地单用户Shell 命令
SSE本地/远程多用户URL → SSE 端点
Streamable HTTP本地/远程多用户URL → HTTP 端点

📚 addyosmani/agent-skills 深度解析

核心理念：编码技能工作流、质量门禁、最佳实践打包给 AI Agent。

7 个斜杠命令（对应开发周期）：

/spec   → 写 PRD（目标、命令、结构、代码风格、测试、边界）
/plan   → 小而原子的任务分解
/build  → 增量实现（垂直切片、特性开关）
/test   → 测试即证明
/review → 代码审查（5 轴审查，~100 行变更）
/code-simplify → 简化优先于聪明
/ship   → 更快即更安全

20 个核心 Skills 分类：Define/Plan/Build/Verify/Review/Ship 六大阶段，每个阶段包含多个专业化 Skills。

3 个专业 Agent Personas：code-reviewer（高级 Staff 工程师视角）、test-engineer（QA 专家）、security-auditor（安全工程师）。

Anti-rationalization 设计：每个 Skill 都包含"常见借口 + 反驳"表格，防止 Agent 偷懒走捷径。

🌊 ruvnet/ruflo - Claude Agent 编排平台

核心定位：为 Claude 添加多 Agent 编排、自学习记忆、Federation 安全协作。

关键能力：

  • 🤖 100+ Agents：编码、测试、安全、文档、架构专用 Agent
  • 📡 联邦通信层：零信任跨机器/组织协作，mTLS + ed25519 身份验证
  • 🐝 Swarm 协调：分层/网格/自适应拓扑，Raft/Byzantine/Gossip 共识
  • 🧠 自学习：SONA 神经模式 + ReasoningBank + 轨迹学习
  • 💾 向量记忆：HNSW 索引 AgentDB，150x-12,500x 更快搜索
  • ⚡ 12 个后台 Worker：审计、优化、测试缺口等自动触发
  • 🛡️ 安全：AIDefence、PII 检测、CVE 修复、路径遍历防护
  • 🔌 多 Provider：Claude/GPT/Gemini/Cohere/Ollama 智能路由

Federation 安全特性：14 类型 PII 检测管道，传输前自动剥离；行为信任评分公式：0.4×成功率 + 0.2×正常运行时间 + 0.2×威胁 + 0.2×完整性；HIPAA/SOC2/GDPR 合规审计跟踪。

Web UI（flo.ruv.io）：多模型聊天，内置 ~210 个 MCP 工具，一次响应并行执行 4-6+ 工具，记忆跨会话持久化。
