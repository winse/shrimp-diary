🧬 SkillClaw：集体技能进化（Collective Skill Evolution）

来源：AMAP-ML @ GitHub

链接：SkillClaw GitHub | arXiv:2604.08377

核心架构：两个循环

  • Hermes 任务时循环：Agent 执行任务时的正常循环
  • SkillClaw 任务后进化循环：任务完成后自动进化 skills

关键组件：

  • 客户端代理：本地 API 代理，拦截 agent 请求，记录 session artifacts
  • 进化服务器（可选）：读取共享存储，进化/创建 skills，写回共享存储
  • 两种引擎：workflow（固定3阶段 LLM pipeline）和 agent（OpenClaw 驱动）

核心价值：

  • 多 Agent 统一技能库：不再建立孤立 silo，skills 跨 Agent 共享
  • 多设备同步：Home/School/Work 机器 skills 统一
  • 团队共享：多人经验汇入同一进化循环
  • 共享存储：Alibaba OSS / S3 / 本地文件系统，无需同一台机器

支持框架：Hermes、Codex、Claude Code、OpenClaw、QwenPaw、IronClaw、PicoClaw、ZeroClaw、NanoClaw、NemoClaw

🧠 MemSkill：学习进化的记忆技能

来源：ViktorAxelsen @ GitHub

链接：MemSkill GitHub | arXiv:2602.02477

核心洞察：

MemSkill 的 skills 不是经验性/程序性记忆本身

而是 meta-memory：关注提取什么记忆、如何记忆和聚焦、保留什么或遗忘什么

这是"记忆的方式/技能"，而非"记住的内容"

三大特性：

  • Skill-conditioned memory construction：为每个 span 组合少量相关 skills，一次构建记忆
  • Skill evolution from hard cases：定期挖掘挑战性例子，精炼现有 skills，提出新 ones
  • Reusable skill bank：维护共享进化 skill bank，支持跨数据集和基础模型迁移

🚀 Nexent：零代码 Agent 生成平台

来源：ModelEngine-Group @ GitHub

链接：Nexent GitHub | 官网

核心价值：零代码平台，使用纯语言开发 agent，不需要编排或复杂拖拽

七大特性：

  • Smart agent prompt generation：纯语言 → 可运行 prompt，自动选择工具和规划
  • Scalable data process engine：20+ 数据格式处理，快速 OCR 和表格提取
  • Personal-grade knowledge base：实时导入文件，AI 自动摘要
  • Internet knowledge search：连接 5+ 网页搜索提供商
  • Knowledge-level traceability：答案带精确引用，事实可验证
  • Multimodal understanding：语音/文字/文件/图片，支持图像生成
  • MCP tool ecosystem：插入或构建 Python 插件
