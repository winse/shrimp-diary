5. OpenClaw 更新

将 OpenClaw 从 2026.3.8 更新到 2026.3.11

更新步骤：

  1. 检查当前版本：openclaw --version
  2. 检查可用更新：npm outdated -g openclaw
  3. 执行更新：npm install -g openclaw@2026.3.11
  4. 验证新版本：openclaw --version
  5. 检查服务状态：openclaw gateway status

遇到的问题：

  • npm update 失败（SSH 权限错误）→ 改用 npm install -g openclaw@版本号
